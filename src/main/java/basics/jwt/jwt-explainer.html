Anatomy of a JWT

A JSON Web Token is three Base64URL blocks glued together with dots. Nothing more. Below is a real token, color-coded, plus a live demo that runs the exact same HMAC-SHA256 math as the pure-Java class.

Header

Says which algorithm signed this (HS256 here) and that it's a JWT. Base64-decoded, never encrypted.

Payload

The actual claims — user id, role, expiry. Anyone can decode and read this. Never put secrets in here.

Signature

HMAC-SHA256 of header+payload, keyed with a server-only secret. This is the only part that proves the token wasn't forged.

signature = HMAC-SHA256( base64url(header) + "." + base64url(payload), secret )
