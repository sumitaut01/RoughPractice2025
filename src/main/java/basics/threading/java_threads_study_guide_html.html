Java Threads - Complete Study Guide

Understand Multithreading, Thread Lifecycle, Use Cases, Synchronization and Interview Concepts

1. What is a Thread?

A Thread is the smallest unit of execution inside a process. Java allows multiple threads to run simultaneously.

Think of a process as a restaurant and threads as waiters working together. Multiple waiters can serve different customers at the same time.

Real Life Examples

  • WhatsApp downloading file while you continue chatting
  • YouTube buffering video while playing
  • Browser opening multiple tabs
  • Selenium framework running tests in parallel

4. How to Create Threads in Java

Method 1: Extend Thread Class

class MyThread extends Thread {

    public void run() {
        System.out.println("Thread is running");
    }

    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.start();
    }
}
Always use start() instead of directly calling run(). start() creates a new thread internally.

Method 2: Implement Runnable Interface

class MyRunnable implements Runnable {

    public void run() {
        System.out.println("Runnable thread running");
    }

    public static void main(String[] args) {
        MyRunnable obj = new MyRunnable();
        Thread t1 = new Thread(obj);
        t1.start();
    }
}

Which One is Better?

Thread Class Runnable Interface
Inheritance used More flexible
Cannot extend another class Can extend another class
Less preferred Industry preferred

7. Multithreading Example

class Task1 extends Thread {
    public void run() {
        for(int i=1; i<=5; i++) {
            System.out.println("Task1: " + i);
        }
    }
}

class Task2 extends Thread {
    public void run() {
        for(int i=1; i<=5; i++) {
            System.out.println("Task2: " + i);
        }
    }
}

public class Demo {
    public static void main(String[] args) {

        Task1 t1 = new Task1();
        Task2 t2 = new Task2();

        t1.start();
        t2.start();
    }
}
Output order may change every time because threads execute independently.

8. What is Synchronization?

Multiple threads sharing the same resource may create inconsistent results. Synchronization prevents data corruption.

Problem Without Synchronization

Counter = 0

Thread1 increments → 1
Thread2 increments → 1

Expected = 2
Actual = 1

Synchronized Method Example

class Counter {

    int count = 0;

    synchronized void increment() {
        count++;
    }
}
synchronized allows only one thread at a time to access critical code.

10. Thread Pool & Executor Framework

Creating too many threads is expensive. Java provides Executor Framework to reuse threads. 

ExecutorService service = Executors.newFixedThreadPool(3);

service.submit(() -> {
    System.out.println("Task executed");
});

service.shutdown();

Why Thread Pool?

  • Better performance
  • Reuse threads
  • Reduced memory usage
  • Industry standard approach

12. Common Interview Questions

1. Difference between Process and Thread?

Process Thread
Independent program Part of process
Heavyweight Lightweight
Separate memory Shared memory

2. Difference between start() and run()?

start() run()
Creates new thread Normal method call
Runs asynchronously Runs in same thread
Calling run() directly does NOT create a new thread.

3. What is Synchronization?

Synchronization is a mechanism that allows only one thread at a time to access critical/shared resources. 

synchronized void printData() {
    // critical section
}

4. What is Thread Safety?

Thread-safe code behaves correctly when multiple threads access it simultaneously.

Synchronization, immutable objects and concurrent collections help achieve thread safety.

5. Difference between wait() and sleep()?

wait() sleep()
Belongs to Object class Belongs to Thread class
Releases lock Does not release lock
Used in synchronization Used for delay

6. What is Deadlock?

Deadlock occurs when two or more threads wait forever for each other’s resources. 

Thread1 holds LockA and waits for LockB
Thread2 holds LockB and waits for LockA
Both threads become stuck permanently.

7. What is volatile keyword?

volatile ensures that changes made by one thread are immediately visible to other threads. 

volatile boolean running = true;
volatile provides visibility, but not thread safety for complex operations.

8. Why is ExecutorService preferred over manual threads?

  • Reuses threads efficiently
  • Improves performance
  • Better memory management
  • Easier task handling
  • Supports thread pools
ExecutorService service = Executors.newFixedThreadPool(5);

9. What is Race Condition?

Race condition happens when multiple threads modify shared data simultaneously, causing unpredictable results.

10. What is join() method?

join() makes one thread wait until another thread completes execution. 

t1.start();
t1.join();
System.out.println("Thread completed");
