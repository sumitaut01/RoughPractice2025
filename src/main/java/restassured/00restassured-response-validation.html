1.Checking status code

Two common styles: BDD-style assertion, or pulling the raw int for custom logic.

// BDD style — fails the test immediately if mismatched
given()
    .baseUri("https://api.example.com")
.when()
    .get("/users/1")
.then()
    .statusCode(200);

// Range / matcher style
.then()
    .statusCode(anyOf(is(200), is(201)));

// Pull the raw status code for custom checks/logging
Response response = given().get("/users/1");
int statusCode = response.getStatusCode();
Assert.assertEquals(statusCode, 200);

2.Checking response time

RestAssured gives you both a fluent assertion and a raw value in milliseconds.

// Assert directly — fails if response takes 2000ms or more
given()
    .get("/users/1")
.then()
    .time(lessThan(2000L), TimeUnit.MILLISECONDS);

// Fetch the raw value for logging / soft assertions / reporting
Response response = given().get("/users/1");
long timeInMs = response.getTime();                       // milliseconds (default)
long timeInSec = response.timeIn(TimeUnit.SECONDS);        // any unit you like

System.out.println("Response time: " + timeInMs + " ms");
Use response.getTimeIn(TimeUnit) (older API) or timeIn(TimeUnit) depending on RestAssured version — both exist across 4.x/5.x, but prefer timeIn() going forward.

3.Fetching the raw body

Response response = given().get("/users/1");

String bodyAsString = response.getBody().asString();
// or shorthand
String bodyAsString2 = response.asString();

byte[] bodyAsBytes = response.asByteArray();

4.JsonPath — fetching specific values

Best when you only need one or two fields and don't want a full POJO.

Response response = given().get("/users/1");

// Option A: via response.jsonPath()
JsonPath jsonPath = response.jsonPath();
String name  = jsonPath.getString("name");
int    id    = jsonPath.getInt("id");
List<String> roles = jsonPath.getList("roles");

// Option B: inline, one-liner
String email = response.jsonPath().getString("email");

// Nested fields
String city = response.jsonPath().getString("address.city");

// Array/list access
String firstRole = response.jsonPath().getString("roles[0]");
List<Map<String,?>> items = response.jsonPath().getList("items");

// Filtering with GPath-style expressions
List<String> activeUserNames =
    response.jsonPath().getList("users.findAll { it.active == true }.name");
JsonPath expressions support Groovy's GPath syntax, so filtering, find, findAll, and simple aggregation (sum(), max()) all work directly on the path string.

5.Deserializing with .as(Class.class)

Best when you want the whole payload mapped to a POJO for readable assertions.

// POJO
public class User {
    private int id;
    private String name;
    private String email;
    // getters/setters
}

Response response = given().get("/users/1");
User user = response.as(User.class);

Assert.assertEquals(user.getName(), "John Doe");

// Works for lists too, via TypeRef
List<User> users = response.as(new TypeRef<List<User>>() {});
Requires a JSON (de)serializer on the classpath — Jackson (jackson-databind) or Gson. RestAssured auto-detects whichever is present.

6.Using .then().extract()

Lets you validate and pull data out in the same fluent chain — very common in real test methods.

Response response =
    given()
        .baseUri("https://api.example.com")
    .when()
        .get("/users/1")
    .then()
        .statusCode(200)
        .time(lessThan(2000L), TimeUnit.MILLISECONDS)
        .extract()
        .response();

// From here, all techniques above apply on `response`
String name = response.jsonPath().getString("name");
User user   = response.as(User.class);

// Or extract a single value directly, without the intermediate Response
String name2 = given()
    .get("/users/1")
.then()
    .statusCode(200)
    .extract()
    .path("name");   // shorthand for jsonPath().get("name")

// Extract just the body as a JsonPath object
JsonPath jp = given()
    .get("/users/1")
.then()
    .statusCode(200)
    .extract()
    .jsonPath();

7.Headers, cookies, content-type

Response response = given().get("/users/1");

String contentType = response.getContentType();
String header      = response.getHeader("X-Request-Id");
Map<String,String> cookies = response.getCookies();

.then()
    .header("Content-Type", containsString("application/json"))
    .contentType(ContentType.JSON);

8.Which approach to use when

NeedUse
Just verify status/time/headers, no data needed.then().statusCode()/.time()/.header()
Pull 1–2 fields quicklyresponse.jsonPath().get...()
Full payload mapped to a typed object for assertionsresponse.as(Class.class)
Validate + extract in one fluent chain (typical test method).then().statusCode(200).extract().response()
Need only the raw JSON text (logging, snapshotting, diffing)response.asString()
Filtering/aggregating inside a JSON arrayJsonPath GPath expressions (findAll { }, sum())
In a framework, the common pattern is: chain .then() for the cheap assertions (status, time, content-type), then .extract().response() once, and reuse that single Response object for every further JsonPath / POJO access — avoids re-parsing the body multiple times.
